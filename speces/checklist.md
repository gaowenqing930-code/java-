- [x] 题目指纹（题干规范化+知识点集合+难度）配合唯一索引，重复生成题目不入库
- [x] 练习支持题库/AI/自适应/错题重练四种模式，创建—答题—提交—出分流程走通

- [ ] AI 出题/评测接口按用户限流，API Key 仅存在于服务端配置
- [ ] Docker Compose 可一键部署（MySQL + 后端 + Nginx），新环境可复现演示
